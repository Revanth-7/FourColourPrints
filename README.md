# Four Colour Print

A React and Vite website for Four Colour Print.

## Local development

```sh
npm ci
npm run dev
```

## GitHub Pages

The site is configured for the `FourColourPrints` repository. Pushes to `main`
build the site and deploy it to GitHub Pages using the workflow in
`.github/workflows/deploy.yml`.

In the repository settings, open **Settings → Pages** and set the source to
**GitHub Actions**. After the first successful deployment, the site will be
available at `https://Revanth-7.github.io/FourColourPrints/`.
